# Changelog

## [1.0.0] - 2026-08-09

### Added

- Local scheme database (12 Indian public-benefit schemes)
- Rule-based offline eligibility engine
- Tkinter desktop dashboard (Check Eligibility, Results, Browse, History tabs)
- Standalone HTML/JS web dashboard (no server required)
- Local JSON-based eligibility check history
- Document checklist and apply-mode guidance per scheme
- Contamination-free, 100% offline processing (no APIs, no network calls)
